 脚本功能

  scripts/eval_hover_robustness.py 是一个专门用来测试已训练策略鲁棒性的评估脚本，支持两种测试模式。

  ---
  两种测试模式

  模式一：test=target — 目标位置变动测试

  目的：验证策略能否跟随移动的悬停目标点。

  原理：在 _compute_state_and_obs 上挂一个 hook，每隔 target_change_interval（默认 100
  步）就把目标位置随机移动到 XY 平面 ±1.5m
  范围内的新位置，同时移动场景中的可视化标记。策略每步都能从观测中看到新的
  rpos（相对目标的位置误差），所以理论上能追踪。

  运行命令：
  OMNIDRONES_AMOV_USD_PATH=/home/benhua/OmniDrones/amov_drone_arm_1.usd \
  python scripts/eval_hover_robustness.py \
    task=HoverAmovDynaArm algo=ppo headless=false \
    checkpoint=wandb/run-20260601_002626-jbg781op/files/checkpoint_final.pt \
    test=target \
    target_change_interval=100 \
    target_pos_range=1.5

  ---
  模式二：test=arm_perturb — 机械臂轨迹扰动测试

  目的：验证策略在训练轨迹之外的机械臂运动条件下是否仍能稳定悬停。

  原理：在 _reset_idx 上挂一个 hook，每次 episode
  重置时对每个关节的幅度（amplitude）和频率（frequency）乘以一个随机系数。arm_perturb_scale=0.5
  意味着参数在原始值的 50%～150% 之间随机变化。这直接模拟了"机械臂运动模式与训练时不同"的场景。

  运行命令：
  OMNIDRONES_AMOV_USD_PATH=/home/benhua/OmniDrones/amov_drone_arm_1.usd \
  python scripts/eval_hover_robustness.py \
    task=HoverAmovDynaArm algo=ppo headless=false \
    checkpoint=wandb/run-20260601_002626-jbg781op/files/checkpoint_final.pt \
    test=arm_perturb \

  运行命令：
  OMNIDRONES_AMOV_USD_PATH=/home/benhua/OmniDrones/amov_drone_arm_1.usd \
  python scripts/eval_hover_robustness.py \
    task=HoverAmovDynaArm algo=ppo headless=false \
    checkpoint=wandb/run-20260601_002626-jbg781op/files/checkpoint_final.pt \
    test=arm_perturb \
    arm_perturb_scale=0.5

  OMNIDRONES_AMOV_USD_PATH=/home/benhua/OmniDrones/amov_drone_arm_1.usd \

  这一步机械臂保持训练时的 arm_hold 姿态（全零关节），目标位置固定在
  (0,0,2)，和训练条件完全一致。episode_len 应该接近 500，pos_error 应该接近训练时的
  0.038m。
